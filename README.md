# Página de Vendas

Site estático (HTML puro, sem dependências) pronto para deploy na Vercel.

## Deploy na Vercel

Depois de subir este repositório para o GitHub:

1. Acesse https://vercel.com/new
2. Clique em "Import Git Repository" e selecione este repositório
3. A Vercel detecta automaticamente que é um site estático — não precisa configurar build command nem output directory
4. Clique em "Deploy"

Pronto — a cada `git push` na branch principal, a Vercel publica a nova versão automaticamente.
